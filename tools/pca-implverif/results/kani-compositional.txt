Diagnosis (CBMC symex traces, "Unwinding loop/recursion" counts):
  - serde_json Value clone / PartialEq / drop are recursive; with a symbolic variant CBMC unrolls the recursion at every
    level (Value -> Map -> Vec<Value> -> ...). Fixed in the harnesses: no clone, a non-recursive comparison, values leaked.
  - std BTreeMap<String, _> with heap String keys: each key comparison is a memcmp over heap bytes that symbolic
    execution does not fold, so insert positions become symbolic and the node-restructuring loops
    (correct_childrens_parent_links) are unrolled thousands of times. This affects the real Verdict.checks map
    (9 inserts) in every decision harness and any real serde_json Map with more than one entry.
  - Kani 0.68 cannot stub a trait's PROVIDED method for one Self type (Iterator::all, Engine::decode) and resolves
    <T as Trait>::m only for methods defined in that impl; `core::cmp::PartialEq` in a stub path resolves to the derive
    macro. So the alphabet scan and string equality could not be replaced by loop-free contracts (any-length wrapper
    harness dropped); the decoding loop (<GeneralPurpose as Engine>::internal_decode, defined in the impl) is the contract.
